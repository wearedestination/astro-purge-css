# Agent instructions

Follow [.github/CONTRIBUTING.md](.github/CONTRIBUTING.md). Before handing work back, run:

```console
npm run check

npm test
```

## Authorship

The person who prompted you is the author of the work and owns it. Don't add a `Co-Authored-By` trailer, or any
credit to Claude, Anthropic or another AI tool, anywhere: code, commit messages, pull request titles and bodies, or
review and issue comments.
